# VISE Seguridad - Sitio Web

Este proyecto consiste en el desarrollo de una página web para la empresa **VISE Seguridad SpA**, con el objetivo de presentar sus servicios de forma clara, profesional y accesible para potenciales clientes.

---

##  Objetivo

- Crear presencia digital para la empresa  
- Mostrar servicios de seguridad privada  
- Facilitar el contacto con clientes  
- Servir como base para futuras mejoras y funcionalidades  

---

## Secciones del sitio

- **Inicio**: Presentación general de la empresa  
- **Nosotros**: Información sobre la empresa y su experiencia  
- **Servicios**: Detalle de los servicios ofrecidos  
- **Contacto**: Información de contacto y futuras consultas  

---

##  Tecnologías utilizadas

- HTML  
- CSS  
- JavaScript (en desarrollo)  

---

##  Estado del proyecto

El proyecto se encuentra actualmente en desarrollo, trabajando en la estructura base y estilos iniciales.
